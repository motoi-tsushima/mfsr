# mfsr - Multi-file String Replace

Fast cross-platform text replacement tool for developers.

## 🚀 Quick Start

```bash
# Install as .NET Tool
dotnet tool install -g mfsr

# Replace text
mfsr -r:replace.csv "*.txt" 

# Change the newline character to the Unix type.
mfsr "*.txt" /nl:unix
```
