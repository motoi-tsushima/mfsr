# mfprobe - Multi-file Probe

Fast cross-platform file search tool for developers.

## 🚀 Quick Start

```bash
# Install as .NET Tool
dotnet tool install -g mfprobe

# Probe for text
mfprobe "*.txt" -d

# Search with file pattern
mfprobe -s:search.txt -f:filelist.txt
``
